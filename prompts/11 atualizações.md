Contexto: Aplicação web já funcional (app/static, app/api, app/services), com um gráfico por repositório e os modos "Ver como gráfico" e "Ver como tabela"; os relatórios coletados ficam no banco com generated e verdict de todas as iterações; "evolução temporal" consta como fora de escopo em docs/01 escopo-mvp.md.
Objetivo: (1) Cada painel deve ter um botão "Atualizar" que só coleta se o último commit do branch for diferente do último coletado, exibindo o commit no painel e avisando quando não há novidade; (2) Criar o modo "Ver como tendência", que plota um stacked line chart por repositório com a evolução no tempo das features por veredito, com seletor de fase (padrão Tests), calculado só com os dados do banco (sem novas chamadas ao GitHub) por um endpoint GET /api/trend; (3) Atualizar escopo e backlog.
Estilo: Python tipado e FastAPI em camadas; HTML, CSS e JavaScript simples com Chart.js, sem novas dependências; mesmas cores por veredito dos demais gráficos; acessível e compatível com tema claro e escuro; testes com cliente GitHub em memória.
Resposta: Código completo dos arquivos alterados em app/static, app/api, app/services e app/models, testes, e os trechos atualizados de docs/01 escopo-mvp.md (remover "evolução temporal" do fora de escopo) e docs/02 backlog.md.
